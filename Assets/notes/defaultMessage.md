# Welcome to KoBar!

**Your modular, always-on-top desktop note sidebar.**
A lightweight note-taking tool that lives on the edge of your screen.

## 📝 Notes Management
- **Favorite:** Click the star icon on the left of a note tab to favorite or unfavorite it. Favorited notes appear in the favorites list.
- **Delete:** Hover over a note tab and click the × icon at its right to delete the note.
- **Two-column tabs:** All notes are shown as two-column tabs; click to switch quickly between them.

## 🛠 Quick Actions (button row at the bottom of the panel)
- **Add New Note:** Create a blank note with one click.
- **Read / Edit Mode:** Switch between reading mode and Markdown editing mode. In edit mode you can format text with headings, lists, bold, text colors and images.
- **Favorites:** View and manage all favorited notes.
- **Copy Entire Note:** Copy the full content of the current note to the clipboard.
- **Settings:** Open the settings panel.

## ⚙️ Settings Panel
- **Document Save Path:** Choose the folder where notes are exported as text files, or restore the system default (Documents folder).
- **UI Layout Settings:** Adjust sidebar orientation, width, icon scale, feature spacing, editor font size and line height.

Enjoy using KoBar!
